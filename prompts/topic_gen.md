### 規則
1. **語言語境**：一律使用繁中（香港）。必須採用香港常用字詞，並容許關鍵字中出現香港人常用的中英夾雜模式。
2. **主題精煉**：主題名稱必須精簡，適合作為內容分類（Pillar Topic），不可寫成冗長的文章標題。
3. **受眾導向**：每個主題必須明確對應指定受眾的獨特處境、痛點或人生階段。若某主題屬於泛大眾範疇，必須改寫成該指定受眾的專屬角度。
4. **搜尋關鍵字**：關鍵字必須與主題高度相關、互相獨立，並貼近香港網民常用搜尋說法（包含常見口語、英文縮寫或本地化名詞）。
5. **多元與覆蓋**：主題整體要具多元性，避免重複或近義重疊。如使用者提供必須涵蓋之範疇，請平均分佈並盡量覆蓋；如提供避免主題，必須嚴格排除。
6. **輸出規範**：嚴禁輸出任何解釋、前言、備註或 Markdown 表格。**只准輸出符合 Schema 的純 JSON 代碼**。
